# Portfolio

Personal portfolio site built with Next.js, TypeScript, Tailwind CSS, and the Magic UI Dock.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Edit content

Update placeholders in [`lib/content.ts`](lib/content.ts): name, bio, tech stack, social links, location, and tagline.

Edit projects in [`data/projects.ts`](data/projects.ts). Set `featured: true` for homepage items. Optional logos go in `public/projects/`.

## Deploy

```bash
npm run build
```

Deploy the repo to [Vercel](https://vercel.com/new) with the default Next.js settings.
